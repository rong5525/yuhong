# Yuhong · 个人简历网站

一个不依赖框架的一页式个人简历网站，部署于 GitHub Pages，并使用自定义域名 `yuhong.li`。

## 本地查看

直接双击 `index.html`，或在编辑器中启动任意静态文件服务。

## 替换内容

优先在 `index.html` 中替换以下信息：

- 姓名、个人简介与所在地
- 邮箱和社交账号链接
- 工作或实践经历
- 代表项目
- 教育背景与技能

视觉样式集中在 `styles.css`，打印 / 存为 PDF 功能位于 `script.js`。

## GitHub Pages

仓库地址：`https://github.com/rong5525/yuhong`

Pages 使用主分支根目录部署；`CNAME` 文件会把站点绑定到 `yuhong.li`。
